# Security policy

Archived project: no versions receive security fixes. Use only for study or isolated local experiments.

Report vulnerabilities privately using [GitHub private vulnerability reporting](https://github.com/minifish-org/qwen-local/security/advisories/new).
Include affected revision, reproduction steps and impact. Do not post credentials
or exploitable details in public issues. If private reporting is unavailable, do
not post the details publicly.

Keep the service bound to loopback. API keys in the README are client placeholders, not authentication; the service does not enforce access control.
